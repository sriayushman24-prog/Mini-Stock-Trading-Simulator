# Mini-Stock Trading Simulator

## About the Project

This is a Mini-Stock Trading Simulator that I created for my Grade 11 Computer Science culminating project using Java. The program allows users to buy and sell stocks using virtual money.
The simulator starts with a cash balance of $10,000 and allows users to manage their own stock portfolio. Stock prices change randomly after a successful buy or sell, making the simulation more realistic.

## Features

- **View Portfolio:** View owned stocks, current prices, quantities, total stock values, cash balance, and overall net worth.
- **Buy Stocks:** Purchase stocks using the available cash balance.
- **Sell Stocks:** Sell stocks that are already owned and receive money back into the cash balance.
- **Random Price Changes:** Stock prices increase or decrease randomly by up to 5% after a successful transaction.
- **Input Validation:** Handles invalid menu options, stock symbols, and quantities.
- **Portfolio Summary:** Displays the current portfolio and overall net worth.

## Stocks Available

The simulator includes five stocks:

- AAPL — Apple
- AMZN — Amazon
- GOOG — Alphabet (Google)
- META — Meta
- MSFT — Microsoft

## Technologies Used

- Java
- Java standard libraries, including `Scanner`, `Random`, and `DecimalFormat`

## How to Get the Project

You can download or clone this repository to run the program on your computer.

### Option 1: Clone the Repository

1. Install Git on your computer if it is not already installed.
2. Open your terminal or command prompt.
3. Navigate to the folder where you want to save the project.
4. Run the following command, replacing `sriayushman24` with your GitHub username:

   ```bash
   git clone https://github.com/sriayushman24/Mini-Stock-Trading-Simulator.git
   ```

5. Navigate into the project folder:

   ```bash
   cd Mini-Stock-Trading-Simulator
   ```

### Option 2: Download the Project

1. Open this project's GitHub repository.
2. Click the **Code** button.
3. Select **Download ZIP**.
4. Extract the downloaded ZIP file to a folder on your computer.

## How to Run

### Requirements

- Java Development Kit (JDK) installed on your computer.
- A terminal or command prompt.

### Steps

1. Open a terminal in the folder containing `TradingSimulator.java`.
2. Compile the Java program:

   ```bash
   javac TradingSimulator.java
   ```

3. Run the program:

   ```bash
   java TradingSimulator
   ```

4. Follow the menu instructions to view your portfolio, buy stocks, sell stocks, or exit the simulator.
